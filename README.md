# Web Studio

Responsive two-page landing (Studio + Portfolio) built from the **Web Studio 3.0** Figma design, final version (Homework #7).

- Plain HTML / CSS / vanilla JS, no build step — open `index.html` in a browser.
- Breakpoints: mobile `< 768px`, tablet `768–1157px`, desktop `≥ 1158px`.
- Features: header navigation, mobile menu, "Order Service" modal form, portfolio category filters.

## Structure

```
index.html        Studio page
portfolio.html    Portfolio page
css/styles.css    All styles (mobile first)
js/main.js        Modal, mobile menu, portfolio filters
images/           Photos, icons and customer logos exported from Figma
```
